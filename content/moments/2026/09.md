::: 2026-09-10 22:15

晚上把 LevelDB 的 compaction 又读了一遍。所谓「分层」，本质是用写放大换读放大——把随机写先攒在内存和 WAL 里，等积够了再顺序刷盘，代价是同一份数据在多层间反复搬运。

一直没有真正想清楚 `SSTable` 为什么按 key 排序就能二分，今天画了张图才反应过来：文件里存的是 block index，索引本身是有序的，二分发生在索引上，不是数据上。少想一步，就卡一晚上。<span class="emoji-plain">😵</span>

:::

::: 2026-09-03 00:48

博客换上了手绘春日风：背景改成米白纸张色，标题用霞鹜文楷手写体，卡片改不规则手绘边框，樱花元素统一加浅棕墨水描边。

踩了个坑——字体规则不能写在 SCSS 里，Hugo 压缩 CSS 时会把带空格的字体名 `"LXGW WenKai"` 处理成小写无引号的形式，字体直接失效。最后内联写进 `<style>` 标签绕过压缩器才正常。<span class="emoji-plain">🌸</span>

::: 2026-09-02 00:54

给博客换了藕粉配色（`#d49ba8`）。原来的主题默认是灰蓝 `#34495e`，偏沉闷。选藕粉是因为头像本身是浅灰紫调、饱和度极低、明度偏高，属于莫兰迪浅调——配色跟着这个区间走才不打架。

顺手修了个隐蔽问题：主题没定义 `--accent-color-rgb`，而样式里有几处 `rgba(var(--accent-color-rgb), .1)` 依赖它。变量缺失不报错，只是那些背景色静默失效，侧边栏 hover 高亮就这么一直没生效过。<span class="emoji-plain">🎨</span>

:::
