# 写作风格卡（从 SutdownBlog 现有 80 篇旧文提炼）

动笔前必读。这不是"建议"，是硬规则。

## 一、宏观形态

| 维度 | 江舟的做法 |
| --- | --- |
| 开头 | 一句话直给，说明本文从哪几个角度讲、要讲清楚什么。不写"引言/背景"铺垫段 |
| 展开 | 按"是什么 → 为什么 → 怎么做 / 代码实践"推进，允许顺序因题材而异 |
| 结尾 | 不写总结段。最后通常是"代码实践"或最后一个知识点，然后直接 **`## 参考链接：`** |
| 篇幅 | 技术文 1500–4000 字居多，周记类更长，允许分节很细 |
| 视角 | 学习者视角，"我读源码/我看课程时发现了…"，不是权威口吻 |

**开头示例（照抄这个味道）**

> MCP在agent中是个并不陌生的词语，本文将从定义，作用，代码等多个角度尽量详细讲述它最为完整的用法。

> 这周的内容主要是**AI DevOps**（人工智能开发运维）。AI DevOps 是将人工智能技术整合到DevOps实践中…

## 二、语言与句式

- **中英混排**：术语首次出现写中文 + 英文全称 + 缩写，之后用缩写或直接英文
  （如"模型上下文协议（Model Context Protocol，MCP）"）
- **加粗关键概念**：段落里的核心名词一律 `**加粗**`，几乎每段都有
- **口语插入**：允许"其实"、"说白了"、"这里有个坑"、"看图就明白了"、括号补注
  （`emm，上回的方法，这回用的github上的框架了。` 这种语气在旧文里是常态）
- **自问自答**：写到一半抛问题再回答，是真实存在的写法
  （`那么在实际写代码的时候，这部分是如何实现的？`）
- **句子偏长**，用逗号连缀，不刻意短句
- 中英文之间不加空格也 OK（旧文两种都有），但**同一篇内要一致**
- 允许少量 LaTeX（`$x \leftrightarrow y$`），站点开了 KaTeX

## 三、结构习惯

- 并列对比 → **优先 Markdown 表格**（旧文里表格密度很高，维度对比几乎都用表格）
- 流程 / 步骤 → 编号列表，`1. 2. 3.` 或裸 `1 2 3`
- 三级标题允许**英文小标题**：`### Why` / `### Limitations` / `### Setup`
- 技术文**几乎都有代码实践章节**，代码块带语言标注
- 引用他人内容会**显式声明并署名**：
  （`感谢这个博主MrCroxx，看了这么多对leveldb的讲解，他的文章是最为明了的！本文中有部分引用他的原文，在此先声明。`）
- 层次：`##` 一级节，`###` 二级，`####` 三级。**最多到 `####`**，靠 `toc: true` 自动生成目录

## 四、反 AI 味黑名单（命中即重写该段）

**禁止出现的套话**

- 「在当今…的时代」「随着…的不断发展」「日益重要」「扮演着至关重要的角色」
- 「值得注意的是」「需要注意的是」「不难看出」「众所周知」
- 「首先 / 其次 / 再次 / 最后」四连作为全文骨架
- 「综上所述」「总而言之」「总的来说」——**结尾不写总结段**
- 「不仅仅是 A，更是 B」「让我们深入探讨」「希望对你有所帮助」
- 每段结尾都来一句升华总结

**禁止的形态**

- 全篇没有一张图、没有一个表格、没有一段代码（技术文）
- 每个二级标题下篇幅完全均等（AI 平均分段的典型特征）
- 大量破折号排比：`——不是…——而是…——更是…`
- emoji 当小标题装饰
- 通篇零第一人称、零口语、零个人判断（这种"无菌体"最像 AI）
- 列举 5 条以上的平行要点且每条都 20 字左右

**自检三问（写完必做）**

1. 这篇文章里有没有一句"只有江舟会这么写"的话（踩坑、吐槽、个人取舍）？没有 → 补
2. 删掉所有加粗和表格后，还看得出结构吗？看不出 → 说明结构靠格式堆的，重写
3. 有没有哪一段是"任何人都写得出来的正确废话"？有 → 删或换成具体例子

## 五、分类差异

| 分类 | 基调 |
| --- | --- |
| ai / cs-code | 概念 + 对比表格 + 代码实践，紧跟课程/技术动态 |
| leveldb / C++ / os / go | 源码阅读型，贴代码 + 逐段讲解 + 引用他人博客 |
| algorithm | 题目 + 思路 + 代码，简洁 |
| book | 读书笔记，观点 + 摘录 + 个人感想 |
| log | 踩坑记录，第一人称叙事最强，口语最多 |
| recreation | 轻松随笔 |

写之前先看该分类下最近 3 篇，以最近 3 篇为准（风格会随时间变化，早期文章偏教程体，近期偏概念+实践）。
